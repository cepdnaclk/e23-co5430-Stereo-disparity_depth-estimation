1. Mathematical Formulation & Problem Definition

Stereo depth estimation computes the 3D scene depth from a pair of rectified, horizontally displaced 2D images ($I_L$ and $I_R$). Because the cameras are rectified along parallel optical axes separated by a known horizontal baseline $B$ with focal length $f$, corresponding physical points share identical vertical coordinates:

$$d(x, y) = x_L - x_R \quad (d \ge 0)$$ $$Z(x, y) = \frac{f \cdot B}{d(x, y)}$$
  • Disparity ($d$) is inversely proportional to metric depth $Z$. Close objects show high disparity, while background features approach $0$.
  • When extrinsic calibration (baseline $B$) or intrinsic matrix ($f$) is uncalibrated, normalized inverse disparity acts as relative depth ($Z_{rel} \propto 1/d$).

Detailed Algorithmic Breakdown:

  • StereoBM (Block Matching): Slides a fixed $K \times K$ window along scanlines minimizing Sum of Absolute Differences (SAD). Extremely fast ($<10\text{ ms}$), but produces block artifacts and completely fails in smooth/textureless regions.
  • StereoSGBM (Semi-Global Matching): Minimizes a 2D global energy functional over 8 independent 1D dynamic programming paths with pairwise smoothness penalties $P_1$ (slanted surfaces) and $P_2$ (depth discontinuities). Runs in $15\text{–}30\text{ ms}$.
  • RAFT-Stereo (Lipson et al., 3DV 2021):
    1. Feature Extraction: Dual Siamese residual network extracts multi-scale feature maps at $1/8$ resolution.
    2. 1D Epipolar Correlation Pyramid: Computes full all-pairs dot products along horizontal scanlines across 4 multi-scale pooling levels.
    3. Recurrent Multi-Scale ConvGRU: 32 iterations of Gated Recurrent Units continuously refine disparity estimates ($d_{t+1} = d_t + \Delta d_t$).
    4. Convex Upsampling: A learned $3 \times 3$ convex combination mask upsamples the $1/8$ disparity back to full native resolution without bilinear edge blurring.

    Note over RAFT: Move weights to CUDA -> 32 ConvGRU iterations -> Convex upsample
    RAFT-->>App: Disparity array [H, W] + Inference ms

    App->>RAFT: self.model.to('cpu') + torch.cuda.empty_cache()
    App->>ZeroGPU: Release GPU slice back to pool

    App-->>User: SSE stream event: complete (Colorized Disparity + Markdown Stats)

Key Engineering Innovations in Deployment:

  • ZeroGPU Dynamic Multiplexing (@spaces.GPU(duration=60)): Leases NVIDIA A10G GPU compute only during the few milliseconds of active inference, then automatically frees GPU memory with self.model.to('cpu') and torch.cuda.empty_cache().
  • Automated Checkpoint Streaming: Official weights (44.6 MB each) are fetched at boot directly from the Hugging Face Model Hub, keeping the GitHub repository lightweight.
  • Isolated Deployment Script (deploy_to_hf.sh): Uses an ephemeral git index (GIT_INDEX_FILE) to assemble source files without pushing heavy research documents or test binaries.

Cloud GPU Economics Continuous compute unit drain even when idle reading text. ZeroGPU: Uses GPU only during inference ($<1\text{ s}$) and releases it. Zero idle cost; high GPU availability for academic evaluation.
Environment Reproducibility Prone to breakage when Colab updates system Python/CUDA packages. Hermetic Docker container with pinned requirements.txt. Guarantees identical, deterministic behavior over time.
