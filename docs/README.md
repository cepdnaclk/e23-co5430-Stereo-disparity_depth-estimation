# Organization profile metadata

This directory is the project profile entry point used by the organization website.

- `data/index.json` contains the team, supervisor, tag, and image metadata.
- `images/` contains images referenced by the metadata file.
- `index.html` is the GitHub Pages project page.

Update `data/index.json` when team or supervisor details change. Keep image paths relative to the repository so the organization website can resolve them from GitHub.
